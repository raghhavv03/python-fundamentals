# Python Fundamentals

A structured collection of lessons, assignments, and notes covering the core fundamentals of Python programming. This repository documents my learning journey from basic syntax to object-oriented programming and file handling.

## Topics Covered

- Variables, data types, and operators
- Conditional statements (`if`, `elif`, `else`)
- Loops (`for`, `while`) and string operations
- String formatting (`.format()`, f-strings)
- Object-Oriented Programming (classes, objects, constructors, inheritance, polymorphism)
- File handling (read, write, append modes)
- JSON data handling
- Exception handling
- List comprehensions
- Lists, tuples, sets, and dictionaries

## Repository Structure

```
python-fundamentals/
├── lessons/          # Example scripts for each topic (01_part_1.py – 05_part_5.py)
├── assignments/       # Assignment solutions and question PDFs
├── notes/             # Lecture notes (PDF)
└── data/              # Sample data files used by the scripts (JSON, TXT)
```

## How to Run

Clone the repository and run scripts from the project root so relative data paths resolve correctly:

```bash
git clone <repo-url>
cd python-fundamentals
python lessons/01_part_1.py
```

## Purpose

This repository serves as a personal reference and practice log for building a strong foundation in Python — covering core concepts that form the basis for more advanced topics like data analysis, automation, and backend development.
